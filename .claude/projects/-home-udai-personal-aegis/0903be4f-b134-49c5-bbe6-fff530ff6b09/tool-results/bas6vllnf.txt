    35	    """Create a signed JWT access token."""

    47	    creds: HTTPAuthorizationCredentials = Depends(bearer_scheme),
    48	    db: Session = Depends(get_db),
    49	):
    50	    """FastAPI dependency: decode JWT and return the User row."""
    51	    from app.models import User
    52	
    53	    try:
    54	        payload = jwt.decode(creds.credentials, settings.jwt_secret, algorithms=[settings.jwt_algorithm])
    55	    except JWTError:
    56	        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid token")
    57	
    58	    user_id = payload.get("sub")

    60	        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="Invalid token payload")
    61	
    62	    user = db.query(User).filter(User.id == uuid.UUID(user_id), User.is_active.is_(True)).first()
    63	    if not user:
    64	        raise HTTPException(status_code=status.HTTP_401_UNAUTHORIZED, detail="User not found or inactive")

## Findings

> `[P1] Require an unpredictable JWT secret at startup` — The application and Compose configuration both fall back to public literals, while `make up` copies another committed literal into `.env.local`. A tenant admin can obtain the platform admin UUID from the `tenant_created` audit event and forge an HS256 token because authentication uses the token’s `sub` to load that user’s authoritative DB role. Any deployment following the documented defaults therefore permits cross-tenant platform takeover. Reject missing, default, or low-entropy secrets at startup. [.env.local.example:17](/home/udai/personal/aegis/.env.local.example:17), [config.py:10](/home/udai/personal/aegis/services/api-gateway/app/config.py:10), [docker-compose.yml:125](/home/udai/personal/aegis/docker-compose.yml:125), [auth.py:54](/home/udai/personal/aegis/services/api-gateway/app/auth.py:54), [tenants.py:50](/home/udai/personal/aegis/services/api-gateway/app/routers/tenants.py:50).

> `[P1] Protect and serialize platform bootstrap` — `/api/auth/bootstrap` has no operator credential or network restriction, so the first caller reaching a fresh deployment becomes platform admin. The check and insert are also separate operations under normal read-committed transactions, allowing simultaneous requests with different emails to create multiple platform admins. Gate bootstrap with an operator-held secret or out-of-band command and enforce singleton creation transactionally. [auth.py:31](/home/udai/personal/aegis/services/api-gateway/app/routers/auth.py:31), [auth.py:34](/home/udai/personal/aegis/services/api-gateway/app/routers/auth.py:34), [docker-compose.yml:142](/home/udai/personal/aegis/docker-compose.yml:142).

> `[P1] Serve authentication only over TLS` — The documented “production stack” exposes Traefik on port 80, and its only entry point is plaintext HTTP. With no documented external TLS terminator, login passwords and bearer tokens traverse the network unencrypted and can be captured or replayed. Add HTTPS/redirection or explicitly require and document upstream TLS termination. [README.md:19](/home/udai/personal/aegis/README.md:19), [traefik.yml:6](/home/udai/personal/aegis/infra/traefik/traefik.yml:6), [docker-compose.yml:100](/home/udai/personal/aegis/docker-compose.yml:100).

> `[P1] Consolidate the duplicate user-creation route` — Both routers register `POST /api/tenants/{tenant_id}/users`, with the platform-admin-only version registered first. Starlette selects the first matching route, so tenant admins always receive 403 and the intended tenant-admin handler is unreachable. The selected “initial admin” handler also defaults omitted roles to `VIEWER` and permits `PLATFORM_ADMIN`, allowing a tenant-bound identity with global bypass privileges. [tenants.py:130](/home/udai/personal/aegis/services/api-gateway/app/routers/tenants.py:130), [users.py:38](/home/udai/personal/aegis/services/api-gateway/app/routers/users.py:38), [main.py:31](/home/udai/personal/aegis/services/api-gateway/main.py:31), [schemas.py:59](/home/udai/personal/aegis/services/api-gateway/app/schemas.py:59).

> `[P1] Complete the portfolio schema before creating production tables` — The PRD requires `gross_exposure`, `net_exposure`, `risk_policy_id`, and `broker_account_id`, but neither the ORM nor API schemas contain them. Since startup immediately executes `create_all()` and migrations are deferred, Phase 1 establishes an incomplete public/storage contract that cannot represent the required portfolio state and will still need a migration to repair. [models.py:63](/home/udai/personal/aegis/services/api-gateway/app/models.py:63), [schemas.py:78](/home/udai/personal/aegis/services/api-gateway/app/schemas.py:78), [main.py:16](/home/udai/personal/aegis/services/api-gateway/main.py:16), [aegis_trader_multi_tenant_prd.md:362](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:362).

PATCH schemas also permit explicit `null` for non-null database columns; handlers assign those values and flush, producing unhandled 500 responses. Typos can persist unusable roles or invalid operational states. Use enums/Literals plus database constraints, and distinguish omitted fields from forbidden null values.
