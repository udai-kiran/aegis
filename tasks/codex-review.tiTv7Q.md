## Findings

> `[P1] Require an unpredictable JWT secret at startup` — The application and Compose configuration both fall back to public literals, while `make up` copies another committed literal into `.env.local`. A tenant admin can obtain the platform admin UUID from the `tenant_created` audit event and forge an HS256 token because authentication uses the token’s `sub` to load that user’s authoritative DB role. Any deployment following the documented defaults therefore permits cross-tenant platform takeover. Reject missing, default, or low-entropy secrets at startup. > `[P1] Protect and serialize platform bootstrap` — `/api/auth/bootstrap` has no operator credential or network restriction, so the first caller reaching a fresh deployment becomes platform admin. The check and insert are also separate operations under normal read-committed transactions, allowing simultaneous requests with different emails to create multiple platform admins. Gate bootstrap with an operator-held secret or out-of-band command and enforce singleton creation transactionally. > `[P1] Serve authentication only over TLS` — The documented “production stack” exposes Traefik on port 80, and its only entry point is plaintext HTTP. With no documented external TLS terminator, login passwords and bearer tokens traverse the network unencrypted and can be captured or replayed. Add HTTPS/redirection or explicitly require and document upstream TLS termination. > `[P1] Consolidate the duplicate user-creation route` — Both routers register `POST /api/tenants/{tenant_id}/users`, with the platform-admin-only version registered first. Starlette selects the first matching route, so tenant admins always receive 403 and the intended tenant-admin handler is unreachable. The selected “initial admin” handler also defaults omitted roles to `VIEWER` and permits `PLATFORM_ADMIN`, allowing a tenant-bound identity with global bypass privileges. > `[P2] Make platform authentication events observable` — Bootstrap and platform-admin login events are stored with `tenant_id=NULL`, but the only read API requires a tenant UUID and filters for equality, so these highest-privilege events cannot be retrieved through the application.
