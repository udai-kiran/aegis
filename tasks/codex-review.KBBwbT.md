> `[P1] Use a non-superuser application database role` — `POSTGRES_USER` creates the bootstrap superuser, and those same credentials are embedded in the gateway’s `DATABASE_URL`; `init.sql` creates no restricted runtime role. Once tenant tables and RLS are added, gateway queries will bypass RLS, so one missing tenant predicate or injection can expose every tenant’s data. [docker-compose.yml:35](/home/udai/personal/aegis/docker-compose.yml:35), [docker-compose.yml:123](/home/udai/personal/aegis/docker-compose.yml:123), [init.sql:5](/home/udai/personal/aegis/infra/postgres/init.sql:5), [PRD §55](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:1481). PostgreSQL confirms that [superusers always bypass row security](https://www.postgresql.org/docs/current/ddl-rowsecurity.html).

> `[P1] Remove unrestricted Docker-daemon access from the edge container` — The host-facing Traefik container receives `/var/run/docker.sock`; `:ro` prevents filesystem replacement but does not restrict mutating Docker API requests through the socket. Compromising Traefik therefore permits container creation with host mounts and escalation to the Docker host. Use an authorization-filtering socket proxy or similarly constrained discovery endpoint. [docker-compose.yml:100](/home/udai/personal/aegis/docker-compose.yml:100), [docker-compose.yml:103](/home/udai/personal/aegis/docker-compose.yml:103), [traefik.yml:12](/home/udai/personal/aegis/infra/traefik/traefik.yml:12). [Traefik’s own security guidance](https://doc.traefik.io/traefik/v3.1/providers/docker/) warns that unrestricted Docker API access can expose the host.

> `[P1] Terminate TLS before exposing authenticated APIs` — The only host-facing entrypoint is plaintext port 80; there is no HTTPS entrypoint, certificate configuration, redirect, or documented upstream TLS terminator. Deploying this stack as the PRD’s reverse-proxy edge will transmit Phase-1 authentication credentials and session tokens unencrypted. [docker-compose.yml:100](/home/udai/personal/aegis/docker-compose.yml:100), [traefik.yml:6](/home/udai/personal/aegis/infra/traefik/traefik.yml:6), [PRD §65](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:1684), [PRD Phase 1](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:2081).

> `[P2] Bind development data ports to loopback` — The documented dev command publishes PostgreSQL, Redis, and MinIO on every host interface. Redis is especially exposed because protected mode is disabled and no password or ACL is configured, giving any reachable client full command access, including data reads and `FLUSHALL`. Use loopback bindings or authenticate every published service. [docker-compose.dev.yml:2](/home/udai/personal/aegis/docker-compose.dev.yml:2), [docker-compose.dev.yml:5](/home/udai/personal/aegis/docker-compose.dev.yml:5), [redis.conf:11](/home/udai/personal/aegis/infra/redis/redis.conf:11), [docker-compose.yml:124](/home/udai/personal/aegis/docker-compose.yml:124). Docker documents that [omitting a host IP binds all interfaces](https://docs.docker.com/reference/compose-file/services/#ports).

> `[P2] Make phase profiles cumulative` — Activating `phase4` starts `execution-engine` but not the `phase3` risk manager; activating `phase5` starts intelligence without any phase-2/3/4 services. Under the PRD’s cumulative phase model, a later deployment is therefore incomplete, and the execution profile cannot satisfy the invariant that Risk Manager remains in the live execution path. [docker-compose.yml:215](/home/udai/personal/aegis/docker-compose.yml:215), [docker-compose.yml:231](/home/udai/personal/aegis/docker-compose.yml:231), [PRD Phase 3](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:2115), [PRD Phase 4](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:2129), [risk invariant](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:2199).

> `[P2] Prevent cache eviction from deleting coordination state` — Redis is designated for locks and queues, but `allkeys-lru` permits eviction of every key when the 512 MB limit is reached. Memory pressure can therefore silently remove a lock, queued job, or temporary trading state rather than returning an error, causing duplicate work or lost jobs. Separate disposable cache data from coordination state or use a non-evicting policy for the latter. [redis.conf:8](/home/udai/personal/aegis/infra/redis/redis.conf:8), [PRD §59](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:1548). Redis documents that [`allkeys-lru` evicts arbitrary least-recently-used keys](https://redis.io/docs/latest/develop/reference/eviction/).

> `[P2] Stop interpolating raw passwords into a database URI` — `POSTGRES_PASSWORD` is inserted without URI encoding. A valid strong password containing delimiters such as `@`, `/`, `:` or `#` renders a differently parsed URL; for example, Compose produced `postgresql://aegis:p@ss:word/with#chars@postgres:5432/aegis`. Database access will fail once the gateway uses this connection. [docker-compose.yml:123](/home/udai/personal/aegis/docker-compose.yml:123), [.env.example:7](/home/udai/personal/aegis/.env.example:7).

> `[P2] Remove fixed container names from scalable services` — Every service has a global `container_name`. Compose refuses to scale such services beyond one container, and separately named dedicated-tenant projects on the same host will collide with these names. This breaks the PRD’s “one or more containers” and dedicated-runtime paths. [docker-compose.yml:26](/home/udai/personal/aegis/docker-compose.yml:26), [docker-compose.yml:119](/home/udai/personal/aegis/docker-compose.yml:119), [docker-compose.yml:227](/home/udai/personal/aegis/docker-compose.yml:227), [PRD §60–61](/home/udai/personal/aegis/aegis_trader_multi_tenant_prd.md:1587). [Compose scaling constraint](https://docs.docker.com/reference/compose-file/services/#container_name).

> `[P3] Configure Traefik with a network actually shared by the gateway` — Traefik selects the literal network `external`, while Compose renders that network as `aegis-trader_external`, and the labeled gateway is attached only to `internal`. Traefik currently falls back to the gateway’s sole network with a warning, but adding a second gateway network makes selection nondeterministic and can produce 502 responses. [traefik.yml:14](/home/udai/personal/aegis/infra/traefik/traefik.yml:14), [docker-compose.yml:1](/home/udai/personal/aegis/docker-compose.yml:1), [docker-compose.yml:120](/home/udai/personal/aegis/docker-compose.yml:120).
